# Support

Use GitHub Discussions for usage, configuration, and deployment questions.
Include the Strumline version or image digest, deployment shape, sanitized
configuration, and relevant error text. Never post tokens, passwords, raw
telemetry, or private environment details.

Use an issue for a reproducible product defect or focused feature request. Use
the private process in [SECURITY.md](SECURITY.md) for suspected vulnerabilities.

Strumline is maintained on a best-effort basis. Questions and community pull
requests do not have a guaranteed response time. Security-report response
targets are listed separately in the security policy.
